조건문

def 함수명(매개변수)
    return 반환값

클래스: 객체를 만들기 위한 틀
매서드: 함수처럼 생겼음
객체: 클래스를 실행하고 나온 결과
a = 클래스명(속성,속성)
class a :
def__init__(self,속성,속성):

속성: 객체가 갖고있는 정보
인스턴스: 객체마다 다른 속성
클래스: 클래스 전체가 공유하는 속성


__init__ : 클래스를 만들때 처음 실행되는 초기화 함수
self: 클래스 안에서 지금 만들어진 객체, 현재객체자신
self.a: 현재 객체안의 속성 이름은 a
>self를 안붙이면 일반변수, 붙으면 값을 반환할 수 있음

cls : 클래스 자신을 가리킴
@classmethod 클래스 매서드임을 표현하는 표식
> 
__file__: 현재 코드가 있는 파일
os.path : 파일 경로
- .abspath : 상대경로를 절대경로로 바꿈
- .dirname : 경로에서 폴더부분만 가져옴
- .join    : 여러 경로를 이어 붙임
base_dir : (변수명)현재 파일이 들어있는 폴더 경로 지정

KeyError: 없는 키값을 찾을때
